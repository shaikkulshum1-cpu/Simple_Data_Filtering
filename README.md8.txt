# Simple Data Filtering

## Project Description
This project is about creating student records and filtering students based on their marks, age, and department using Python.

## Objective
To understand how conditional statements can be used to filter structured data.

## Technologies Used
- Python
- Jupyter Notebook / VS Code

## Features
- Stores student records using a list of dictionaries.
- Filters students who scored above 80 marks.
- Filters students older than 19 years.
- Filters students belonging to the CSE department.
- Displays the filtered student records.

## Concepts Learned
- Lists and dictionaries
- `for` loops
- `if` conditions
- Comparison operators
- Data filtering

## How to Run
1. Install Python or open Jupyter Notebook.
2. Copy the project code into a Python file or notebook.
3. Run the program.
4. View the student records and filtered results.
